# kikeacosta.github.io

Personal academic website of Enrique Acosta, built with [Academic Pages](https://github.com/academicpages/academicpages.github.io) (Jekyll) and hosted on GitHub Pages.

## Where things live

- `_config.yml` — name, affiliation, sidebar links (Scholar, ORCID, GitHub, ...).
- `_pages/about.md` — the home page.
- `_pages/cv.md` — the CV page.
- `_publications/*.md` — one file per publication. Copy an existing one to add a new paper; `category` must be one of `articles`, `chapters`, `reports`, `working`.
- `_teaching/*.md` — one file per course.
- `images/profile.jpg` — the profile photo.

Pushing to `main` rebuilds the site automatically within a couple of minutes.
